    Methods

    Direct off-target screen

    Both insert orientations are screened for exact 21-base matches and, when enabled, 40-base windows within the selected edit limit. The default allows two differences. Counts refer to distinct insert window starts.

    Read the published sequence-screening approaches. Thakur et al., 2014 · Rual et al., 2007

    Coverage, ranking and upstream similarity

    Coverage means a transcript has at least one exact 21-base match. The search prioritizes the requested isoform set, then minimizes flagged genes or sibling isoforms and matching window starts. For tied candidates it prefers a longer insert, more shared target windows, then more coding sequence where annotated.

    Upstream distances are measured along the spliced transcript to the next exact target block. Treat them as evidence of sequence similarity. Knockdown and transitive silencing require experimental confirmation. Alder et al., 2003
